## Criar o executável (.EXE) no Windows 11

1. Baixe esta branch e extraia o ZIP.
2. Entre na pasta `v1.3`.
3. Dê dois cliques em `CRIAR-EXE.bat`.
4. Aguarde a instalação do PyInstaller e a montagem.
5. O executável será criado em `dist/JVPLEY-1.3/JVPLEY-1.3.exe`.

**Importante:** esta é uma versão empacotada em modo pasta (`onedir`). Mantenha a pasta `JVPLEY-1.3` inteira; não copie o EXE sozinho. O programa abre a interface no navegador e mantém o servidor local ativo enquanto sua janela estiver aberta. O Bluetooth consulta dispositivos reconhecidos pelo Windows; pareamento e áudio continuam sendo feitos pelo Windows. Isso ainda não transforma a interface em uma tela nativa do painel do caminhão.
